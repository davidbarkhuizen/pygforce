====================
PyGForce Feature Set
====================
-----------
IMPLEMENTED
-----------

Generate Semi-Random Test Graph

@ Each Node, Calculate
- Net Force @ Each Node
- Velocity Change & Apply
- Calc & Effect Displacement

Plot Graph

Run Event Based Time Simulation
- periodically add / remove a random node (with its edges) during the
  simulation, keeping the node count within bounds

SELECT NODE USING MOUSE
- single node, left-click to select / deselect (toggle)
- selection shown on the graph rendering: selected node and its
  adjacent edges drawn in the selection colour

DRAG SELECTED NODE
- basic: the selected node's tag x,y co-ords follow the pointer

TOGGLE NODE LABELS
- press Tab (any key) to show / hide node labels
